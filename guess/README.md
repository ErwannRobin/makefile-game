# 🔢 Guess the Number

A simple number guessing game implemented entirely in GNU Make.

## How to Play

```bash
make play
```

The computer picks a random number between 1 and 100. You have to guess it!

## Screenshot

```

  Your guess: 50
  📈 Too low!
  Your guess: 75
  📉 Too high!
  Your guess: 63
  🎉 Correct! You got it in 3 tries!
```

## Rules

- Enter a number between 1 and 100
- The game tells you if your guess is too high or too low
- Try to guess in as few attempts as possible!
