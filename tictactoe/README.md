# ❌ Tic-Tac-Toe

Classic Tic-Tac-Toe vs the computer, implemented in GNU Make.

## How to Play

```bash
make play
```

## Rules

- You play as **X**, the computer plays as **O**
- Enter a number 1-9 to place your mark:
  ```
   1 │ 2 │ 3
  ───┼───┼───
   4 │ 5 │ 6
  ───┼───┼───
   7 │ 8 │ 9
  ```
- First to get 3 in a row wins!
- The CPU plays a strategic game — can you beat it?
